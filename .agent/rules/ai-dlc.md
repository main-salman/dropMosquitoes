# AI-DLC Workflow Steering

When the user invokes AI-DLC, read and follow `.aidlc/aidlc-rules/aws-aidlc-rules/core-workflow.md` to start the workflow.

For rule details, check `.aidlc/aidlc-rules/aws-aidlc-rule-details/` first, then `.aidlc-rule-details/` as a fallback.

Custom project extensions (TDD, Spec-Driven Development) are in `.aidlc-rule-details/extensions/`.
